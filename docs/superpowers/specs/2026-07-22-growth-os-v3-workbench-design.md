# 成长 OS V3 工作台改版说明

## 目标

把当前“所有模块连续堆叠”的页面，改成适合员工每周反复使用的安静工作台。第一屏只回答最重要的问题，其余信息按任务分区展开。

本次只改信息架构、视觉层级、历史周期一致性和响应式体验，不新增需要后端迁移的业务能力，不改变已有权限模型，也不部署远端。

## 成功标准

1. 员工进入个人页后，第一屏能看见本周结论、承诺闭环和下一步，不需要先穿过长篇模块。
2. 周报原文、AI 教练、行动任务、成长轨迹分成四个工作区，同一时间只展示一个。
3. 老板驾驶舱第一屏以管理注意力为核心，组织状态与部门会议进入分区工作台。
4. 切换历史周期时，标题、得分、报告和 AI 内容来自同一周期；无快照时明确提示，不拿最新数据冒充历史数据。
5. 外部链接和历史周期为只读，不展示可误触的点赞、评论、建任务和生成总结操作。
6. 移动端不保留桌面固定侧栏，导航、按钮和图表不溢出、不重叠。

## 视觉方向

- 产品气质：安静、可信、工作导向。
- 参数：视觉变化度 4 / 动效强度 2 / 信息密度 6。
- 背景使用暖灰中性色，绿色只用于增长、完成和关键行动。
- 卡片圆角控制在 6-8px；页区块主要依靠留白和分隔线，而不是层层套卡。
- 状态使用标签，命令使用按钮；不把普通文字都做成胶囊。

## 个人成长页

### 固定首屏

- 身份、周期、得分和趋势摘要。
- 本周焦点：AI 点评结论和三条关键追问。
- 承诺与证据：上周承诺、本周证据、差距、下一验证点。

### 四个工作区

1. 周报与互动：当周完整原文、可见性、点赞与评论。
2. AI 教练：完整点评、教练式提问、自我对照和支持请求。
3. 行动任务：任务候选、方案展开、编辑与创建。
4. 成长轨迹：跨周趋势、雷达、闭环记录和历史周报。

## 老板驾驶舱

### 固定首屏

- 紧凑状态带：提交、P0、跨部门协调、正向样本。
- 管理注意力队列：需要拍板、拆墙、调资源的事项。
- 必读周报：直接进入事实原文。

### 三个工作区

1. 本周决策：管理队列、跨部门协调、公司总结。
2. 组织状态：公司整体情况、闭环雷达、协同评分、部门质量。
3. 部门会议：按部门展开的会议议题和跨周进展。

## 本次从 Kimi PR 取纳的内容

- 采用成长叙事顺序，而不是按数据表字段排列。
- 保留本周焦点、承诺与证据、管理决策优先的核心组件。
- 保留绿色作为“成长/闭环”语义色和前后截图验收方法。

## 本次不直接沿用的内容

- 大面积深绿 Hero 和多层白色大卡。
- 所有模块默认展开的长页面。
- 移动端固定 240px 侧栏。
- 历史周期继续显示最新总分和最新 AI 文案。
- 老板身份退化为可见员工列表第一人。
- 外部只读视图仍显示可写操作。
